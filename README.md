# 🛩 《中国人能飞》

一款单文件网页飞机大战游戏（Canvas 2D + 原生 JavaScript，零外部依赖）。

## 🎮 玩法

- **关卡模式**：3 大关卡 + Boss 战，通关结算红包奖励
- **无尽模式**：无限挑战，Boss 每 20 秒刷新，外星人障碍越飞越快
- **每日彩蛋**：每天 1 架金色大飞机，击落 +800 分 + 5 红包
- **段位系统**：见习机长 → 传奇机长，共 6 档，条件化晋级
- **商店系统**：装备、皮肤、技能、领域四大类，红包货币
- **登录系统**：注册 / 登录 / 注销，数据按账号隔离存储于浏览器本地

## 🕹 操作

| 按键 | 功能 |
|---|---|
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| M | 火力支援技能 |
| P | 暂停 |

## 💾 数据说明

- 所有游玩数据保存在**浏览器 localStorage** 中，按账号隔离（`ccf_u_<用户名>_*`）
- 纯静态托管，换设备/换浏览器需重新注册
